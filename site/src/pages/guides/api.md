# API reference

The reference is generated from the packages' TypeScript with **TypeDoc** on every build, so it
matches the code you install rather than a hand-written summary.

[Open the API reference →](/api/index.html)

It covers:

- **`@mk7s/hologpu`** — `createEffect`, the DOM entry (`attach`), the custom element and the
  recipes helpers.
- **`@mk7s/hologpu-react`** — `HoloField`.
- **`@mk7s/hologpu-dom`** — `attach`, `Attachment`, the CSS/timeline bridges and the field element.
- **`@mk7s/hologpu-core`** — `fragmentEffect`, `defineEffect`, `ParamStore`, the runtime, passes and
  the WGSL chunks.

For prose, the [quick start](/guides/getting-started/) and the
[authoring guide](/guides/authoring/) explain how the pieces fit together.
